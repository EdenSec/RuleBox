界面

主题 跟随系统时会自动匹配操作系统的深浅色。

启用 AI 助手 需要填写可用的接口地址、模型与 API Key（Ollama 可留空）。

系统提示词

内置默认

这是发给模型的角色与输出规则，修改后对所有 AI 对话生效。平台字段上下文与库内示例会由扩展自动拼接，不需要在这里重复； 「禁止编造字段」「授权边界」两条底线要求会始终附加，无法通过修改这里删除。

修改会即时保存到本地浏览器，不会上传；导出配置时会一并导出（API Key 始终置空）。

导入会覆盖设置、自定义平台与条目、收藏与变量记忆；API Key 需要重新填写。 单文件大小上限 500 KB，自定义条目上限 500 条。

危险操作

重置全部本地数据 包含设置、API Key、收藏、最近使用、变量记忆与自定义条目，操作不可撤销。

关于

RuleBox 是面向安全测试场景的本地速取面板，不收集任何使用数据。

版本信息

—

内置语法与 Payload 均整理自各平台公开文档与公开测试资料，仅用于获得授权的安全测试、教学与防御研究。 使用前请自行核对字段与语法，因误用造成的后果由使用者承担。

数据来源

隐私与安全

  • 所有语法、Payload、收藏与设置均保存在浏览器本地，不上传服务器。
  • API Key 仅保存在本机扩展存储中，不写入导出文件，也不会出现在日志里。
  • AI 请求只发送到你填写的 Base URL；扩展不会把 Key 发往其他地址。
  • 扩展不注入网页脚本，不读取网页内容，除非你主动使用右键菜单。

异常提示

额度不足、Key 失效、触发限流等异常会直接在 AI 对话里提示具体原因和处理建议，不额外记录，也不向任何第三方推送。
